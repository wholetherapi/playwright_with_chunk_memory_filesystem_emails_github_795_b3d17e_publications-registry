# Halcyon Research — Publications Registry

`registry.json` is the lab's machine-readable publication ledger.

Every entry has the following fields:

- `id` — internal publication id
- `title` — full paper title
- `venue` — the venue where the paper was accepted or published
- `acceptance_date` — the acceptance date recorded by the program committee (YYYY-MM-DD)
- `codeurl` — the public code repository URL, present only when the paper's code has been released publicly

The registry is updated as papers are accepted.
